# Сайт Астемира Шебзухова

Сайт хостится бесплатно на [Render.com](https://render.com) и автоматически обновляется при каждом изменении файлов на GitHub.

---

## ✏️ Как редактировать текст

Весь текст сайта хранится в **одном файле**:

```
public/data/content.json
```

### Шаги для редактирования:

1. Откройте файл [`public/data/content.json`](public/data/content.json) на GitHub
2. Нажмите на иконку карандаша **✏️** в правом верхнем углу
3. Внесите нужные изменения
4. Прокрутите вниз → нажмите **«Commit changes»**
5. Сайт обновится автоматически через 1–2 минуты

---

## 📂 Структура файла content.json

| Раздел | Что редактировать |
|---|---|
| `meta` | Название сайта, описание для поисковиков |
| `nav` | Пункты меню (русский и кабардинский) |
| `home` | Главная страница: имя, подзаголовок, ссылки на соцсети |
| `about` | «Обо мне»: абзацы текста и карточки проектов |
| `activity` | «Деятельность»: список активностей с датами |
| `education` | «Образование»: список учебных заведений |
| `contact` | «Контакты»: телефон, почта, соцсети |
| `footer` | Имя в подвале страницы |

## 🔗 Ссылки в тексте

Чтобы сделать ссылку прямо внутри текста, используйте формат:

```
[текст ссылки](https://адрес-сайта.com)
```

**Пример:**
```json
"Работа ведётся в рамках клуба [«Djarez»](https://www.instagram.com/djarez.club)."
```

Это превратится в кликабельную ссылку «Djarez» на сайте.

## 🖼️ Как добавить фотографию на главную

1. Загрузите фото в папку `public/assets/` (например, назовите `photo.jpg`)
2. В `content.json` найдите строку:
   ```json
   "photo": null,
   ```
3. Замените на:
   ```json
   "photo": "/assets/photo.jpg",
   ```

---

## ➕ Как добавить новый пункт в «Деятельность»

Скопируйте один из блоков внутри `"activity" → "items"` и вставьте его, заполнив своими данными:

```json
{
  "period": "2020 – 2024",
  "title": "Название должности или роли",
  "organization": "Название организации или проекта",
  "description": "Краткое описание деятельности.",
  "url": "https://ссылка-если-есть.com"
}
```

Если ссылки нет — напишите `"url": null`.

## 🌐 Деплой на Render.com

1. Зарегистрируйтесь на [render.com](https://render.com)
2. Нажмите **New → Static Site**
3. Подключите этот репозиторий с GitHub
4. Render автоматически найдёт файл `render.yml` и настроит всё сам
5. Сайт будет доступен по адресу вида `https://shebzukho.onrender.com`

### Подключение своего домена:
1. В настройках Render: **Settings → Custom Domains → Add Domain**
2. Введите ваш домен (например, `shebzukho.ru`)
3. У регистратора домена добавьте CNAME-запись:
   - Имя: `www`
   - Значение: `shebzukho.onrender.com`

## 💻 Локальный просмотр (для разработчика)

```bash
npm start
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

> **Важно:** Из-за работы с JSON через `fetch()` сайт нельзя открыть напрямую как файл — нужен локальный сервер.
